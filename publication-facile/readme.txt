Publiez des articles construits avec Elementor via un formulaire simple, sans ouvrir Elementor.

== Description ==

1. Ajoutez un ou plusieurs articles Elementor servant de modèles (Réglages > Publication Facile).
2. Pour chacun, vérifiez les widgets proposés (titre, résumé, texte, image principale), le nom affiché et la catégorie.
3. La rédactrice utilise le menu « Nouvel article » : elle choisit un modèle (s'il y en a plusieurs),
   puis saisit titre, résumé, texte et image, avec aperçu, brouillon ou publication.

Chaque article reprend la mise en page complète du modèle. Seuls les widgets choisis changent ;
le design, les autres textes et les autres images restent identiques. Le modèle n'est jamais modifié.

Compatible avec Elementor gratuit (Elementor Pro non requis). Aucun service externe.

== Installation ==

1. Extensions > Ajouter > Téléverser l'extension, choisissez le fichier ZIP, puis activez.
2. Réglages > Publication Facile : ajoutez un modèle, vérifiez ses widgets, enregistrez.
3. Menu « Nouvel article ».

== Frequently Asked Questions ==

= Que se passe-t-il si je modifie le modèle dans Elementor ? =
Les nouveaux articles reprennent la nouvelle version. Si un widget choisi a été supprimé,
la page de réglages l'indique et le formulaire est bloqué jusqu'à correction.

= Puis-je retoucher un article dans Elementor ensuite ? =
Oui. Le formulaire simple ne modifie ensuite que le titre, le résumé, le texte et l'image.
